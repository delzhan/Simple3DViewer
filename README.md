# Simple3DViewer

Simple3DViewer – это интерактивный 3D-редактор, разработанный на Java с использованием JavaFX для визуализации. Проект предоставляет инструменты для загрузки, просмотра, редактирования и сохранения 3D-моделей в формате OBJ с поддержкой текстур и освещения.

## ✨ Основные возможности

### 🎨 Визуализация
- **Три режима отображения:**
    - **Каркасный режим (Wireframe)** – отображение только граней модели
    - **Текстурированный режим** – загрузка и наложение текстур
    - **Режим с освещением** – расчёт освещения и теней
- **Поддержка формата OBJ** с текстурными координатами и нормалями
- **Автоматическая загрузка текстур** при открытии модели

### 🔧 Трансформации моделей
- **Масштабирование** по осям X, Y, Z
- **Вращение** вокруг трёх осей
- **Перемещение** в пространстве
- **Сброс трансформаций** к исходному состоянию
- **Выделение цветом** активных моделей

### 🖥️ Управление сценой
- **Загрузка нескольких моделей** одновременно
- **Выделение моделей** (одиночное/множественное)
- **Удаление моделей** с подтверждением
- **Очистка всей сцены**
- **Сохранение моделей** в формате OBJ

### 🎥 Управление камерой
- **Перемещение в 6 направлениях** (WASD + Space/Shift)
- **Вращение камеры** с помощью мыши
- **Приближение/отдаление** колесом мыши
- **Поддержка нескольких камер** с переключением
- **Плавное перемещение** с клавиатуры

### 🎨 Пользовательский интерфейс
- **Две цветовые темы:** светлая и тёмная
- **Интуитивная панель управления** с разделами:
    - Управление моделями
    - Трансформации
    - Управление камерой
    - Режимы рендеринга
- **ColorPicker** для изменения цвета моделей с поддержкой темной темы
- **Статус-бар** с информацией о состоянии
